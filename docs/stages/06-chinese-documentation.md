# 阶段 06 — 文档中文化

## 阶段成果

将仓库内面向开发者和演示人员的 Markdown 文档统一为中文，使项目的安装、架构、接入、演示、
决策记录、评测结论和阶段实现过程可以直接以中文阅读。

## 实现步骤

1. 盘点仓库中的全部 Markdown 文档，确认 README、架构、事件协议、ADR、报告和阶段总结的范围。
2. 翻译标题、正文、表格、列表和 Mermaid 图示标签。
3. 保留命令、API 路径、代码标识、界面按钮名，以及 Issue、Release、Source Map 等必要技术术语。
4. 统一中文标点和术语表达，同时保持原有链接、代码块与文档结构不变。
5. 使用 Prettier 重新检查全部文档格式，并通过 Git 空白错误检查。

## 验证方式

```bash
pnpm format:check
git diff --check
```

结果：仓库内全部 Markdown 文档已完成中文化，Prettier 格式检查与 Git 空白检查均通过。
