# ADR 0009：评测看可靠性和过程，模型调用可录制回放，裁判可换、可校准

- 状态：已采纳，扩展 ADR 0003 里的评测部分
- 日期：2026-10-01

## 背景

第一版评测（2026-09-27）每个引擎每个用例只跑一次，只看结论，裁判和被测模型是同一个模型，四个问题：

1. **一次的分数不稳定。** 模型有随机性，同一个用例这次对、下次可能错。线上排障要的是「每次都对」，不是「运气好时对」。
2. **只看结论，看不到过程。** 碰巧说对但没看过关键证据、同样的工具同样的参数调两遍、报告被驳回重交，分数都一样。
3. **离不开密钥。** 真实模型评测要花钱、结果不可复现，进不了 CI；改了工具输出格式，要等下一次有人手动跑评测才知道
   模型当时的引用还对不对得上。
4. **裁判本身没被检验。** 裁判与被测模型同源有自我偏好；更根本的是，从来没有人工标注去验证裁判的结论。

行业做法：τ-bench 用 pass^k（k 次全部成功）衡量 Agent 的可靠性；LangSmith、Braintrust 等评测平台把轨迹（调用了哪些
工具、顺序）作为单独的评测维度；前端测试里的 MSW、Polly.js 录制 HTTP 响应后回放；LLM-as-judge 的研究普遍要求
用人工标注校准裁判，报告一致率与 Cohen's kappa。

## 决策

1. **重复试验**：模型引擎每个用例默认跑 3 次（`--runs`），报告 pass@1（平均成功率）、pass^k（任取 k 次全部成功，
   无偏估计 C(c,k)/C(n,k)）和每一轮的分数范围。确定性引擎只跑一次。
2. **轨迹指标**（`eval/trajectory.ts`）：从调查时发出的事件（与界面收到的 SSE 事件相同）里统计工具调用数、重复调用、
   失败调用、被驳回的报告，以及**关键证据工具召回**——每个用例标注参考根因依赖的证据在哪些工具的结果里
   （`evidenceTools`），Agent 一次都没成功调用它们就下了结论，说明结论不是从那份证据来的。
3. **离线 Agent 引擎 `agent-local`**：离线脚本驱动同一个循环、同一批工具和引用核对，不需要密钥，CI 里也有轨迹指标。
   它不是模型推理，报告里单独列出。
4. **录制与回放**（`eval/cassette.ts`）：`--record` 把模型每一轮的回复存成录制文件；`--replay` 用录制驱动当前的循环和
   工具，不需要密钥就能复现结果表。`replay.test.ts` 在 CI 里回放全部录制，步数、调用序列、引用核对任何一项和录制时
   不同就失败。为了让回放的工具输出逐字一致，用例数据只由一个时钟决定（`prepareCase(..., clock)`），录制时记下它。
5. **裁判可换**：`EVAL_JUDGE_API_URL`、`EVAL_JUDGE_API_KEY`、`EVAL_JUDGE_MODEL` 可以指向另一家服务商；报告注明裁判
   是否与被测模型同源。裁判 temperature 取 0，重复试验的差异只来自被测模型。`--replay --rejudge` 可以让新裁判给
   同一批录制下来的报告重新打分。
6. **裁判校准**（`eval/agreement.ts`）：从结果生成盲评标注文件（没有引擎名和裁判结论，顺序打乱），人工填写后计算
   裁判与人工的一致率和 Cohen's kappa（三档与二档两种口径），列出每一条分歧。

## 替代方案

- **只把单次运行跑得更多（更多用例）**：样本大了，但单次的随机性仍然混在分数里，回答不了「同一个问题每次都能查对吗」。
- **用评测平台（LangSmith、Braintrust、promptfoo）**：功能更全，但要接入外部服务或额外依赖；这里的需求几百行代码
  就能讲清楚，面试时每个数字怎么来的都能说明白。
- **在 HTTP 层录制（nock、Polly.js）**：录的是流式响应的字节，和 SDK 版本、分块方式绑死；在 `ModelClient` 接口这一层
  录制，回放时与具体服务商无关。
- **回放时要求请求逐字相同**：提示词或工具输出一改所有录制就作废，而重新录制需要密钥。现在的做法是：行为（步数、
  调用、引用核对）必须一致，工具输出内容变了只提示「录制可能需要更新」。
- **编造人工标注或用另一个模型的结论代替**：那就不是校准了。标注文件随仓库提供，由人填写。

## 影响

- 一次完整评测的模型调用量约为原来的 3 倍（模型引擎各跑 3 次），裁判调用也随之增加。
- 录制文件随仓库提交（每个用例一个 JSON），提示词版本或工具清单变化后，`--replay` 会提示哪些录制已经过时。
- 关键证据工具是人工标注，和参考根因一样有「出题人知道答案」的偏差；召回只说明看没看过，不说明看懂了。
- 人工标注需要人花时间；没有标注时一致性命令只会提示去标注，不会给出数字。
